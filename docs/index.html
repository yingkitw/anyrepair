A Rust crate for repairing malformed structured data

Add anyrepair to your project, call repair(), or use the anyrepair binary. Sixteen formats, streaming, MCP server — built on the standard library only.

src/main.rs 
use anyrepair::repair;

fn main() -> Result<(), Box<dyn std::error::Error>> {
    let broken = r#"{"name": "John", age: 30,}"#;
    let fixed = repair(broken)?;
    println!("{}", fixed);
    // {"name": "John", "age": 30}
    Ok(())
}

Three ways to use the crate

As a library

Import format-specific repairers or the top-level repair() with auto-detection. See module docs on docs.rs.

As a CLI binary

cargo install anyrepair for repair, batch, stream, validate, and repair-binary subcommands in scripts and CI.

As an MCP server

Optional mcp_server binary exposes repair tools to editors and agents — same crate, no extra runtime deps.

Cargo.toml [dependencies]
anyrepair = "0.2.12"
CLI (from the same crate) cargo install anyrepair
anyrepair repair input.json --format json --dry-run --diff
