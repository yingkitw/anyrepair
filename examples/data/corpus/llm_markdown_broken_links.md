# Project Documentation

## Overview

This project is a [Rust library](https://github.com/yingkitw/anyrepair for repairing structured data.

## Features

- **Multi-format support**: JSON, YAML, XML, TOML, CSV, INI
- **Auto-detection**: Automatically detects the format
- **Streaming**: Process large files efficiently
- **MCP Server**: Integration with Claude and other MCP clients

## Installation

Add the following to your `Cargo.toml`:

```toml
[dependencies]
anyrepair = "0.2.9"
```

## Usage

See the [API docs](https://docs.rs/anyrepair and the [README](../README.md for more details.
